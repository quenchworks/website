summary: "Chhoto URL 7.11.4 llegó al catálogo con un chart firmado: un acortador de URL autoalojado con interfaz web, claves de API, enlaces que caducan, contador de visitas e inicio de sesión OIDC, sobre SQLite. La imagen se compila desde el código fuente con cargo auditable. El chart genera la contraseña de la interfaz y una clave de API de 64 bytes, las conserva en las actualizaciones y ofrece un Ingress para TLS, ya que la aplicación no escucha en TLS. Su puerta de instalación añade un enlace con la clave generada, sigue la redirección, rechaza una clave y una contraseña incorrectas y conserva el enlace tras reiniciar el pod."

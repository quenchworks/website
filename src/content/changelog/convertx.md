date: 2026-11-16
summary: "ConvertX 0.20.0 joined the catalog with a signed chart: a self-hosted file converter for images, video, audio and office documents. The image compiles the Bun app from source into one binary and takes its converters from Wolfi: ImageMagick, GraphicsMagick, FFmpeg, LibreOffice, libheif, libjxl, Poppler and Potrace. Converters whose tools Wolfi does not package, such as pandoc, Inkscape and Calibre, are left out of the UI, so it never offers a conversion the image cannot run. LibreOffice runs through its native launcher, since the image has no shell. The chart claims the first account with a post-install Job, where upstream lets the first visitor register it. Its install gate converts an image with ImageMagick and a text file to PDF with LibreOffice, and checks that a second registration is refused."

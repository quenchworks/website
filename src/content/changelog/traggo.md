summary: "traggo 0.8.3 joined the catalog with a signed chart: tag-based time tracking with dashboards, a web UI and a GraphQL API, on SQLite or PostgreSQL. The image builds the Go server, with its GraphQL code generated at build, and the React UI from source, with the golang.org/x modules, go-sqlite3 and gorilla/websocket raised to fixed releases. The chart creates the first admin from a generated Secret, where upstream would create admin/admin. Its install gate signs in over GraphQL, checks that admin/admin, a wrong password and an anonymous query are refused, creates a tag, and finds it again after a restart and an upgrade."
